# Rock-Paper-Scissors-Game
A console-based Rock Paper Scissors game implemented in C++ using procedural Programming (Functions, Enums, arrays, and Struct) the player against the computer for a customizable number of rounds, with a details final summary declaring the overall winner.
Features
Choose number of questions from 1 to 10
Difficulty levels: Easy, Medium, Hard, or Mixed
Operation types: Addition, Subtraction, Multiplication, Division, or Mixed
Random question generation
Tracks right and wrong answers
Shows pass/fail final result
Allows replaying the game
